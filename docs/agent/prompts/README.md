# Prompts

Paste one of these into a session started in the repository root. Each file is the prompt text, ready to copy.

| Prompt | When to use it | How often |
| --- | --- | --- |
| [`continue.md`](continue.md) | Run the next design task, the one the tracker's next action names. Typing `continue` does the same. | Most sessions |
| [`revisit.md`](revisit.md) | Change an earlier decision. Fill in the decision and the reason first. | Occasionally |
| [`audit.md`](audit.md) | Check the whole design for consistency: spec, grammar, formal rules, examples, glossary, links. | About every five tasks |

Keyword: `pause` stops a task partway, saves a handoff in the tracker, asks about the commit, and stops. The task
steps all of these follow are in [`../workflow.md`](../workflow.md), section 3.
