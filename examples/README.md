# Examples

QubeC programs (`.qbc`) that show the language as decided so far. Every file uses decided syntax only; anything
undecided is labelled *provisional syntax*. Once a grammar checker exists, every example is checked against
[the grammar](../docs/spec/grammar/qubec.ebnf).

## Header convention

Every example starts with a comment header (in comment syntax once M02 decides it; until then the header is
provisional syntax):

```
// <file name>: <one line on what it shows>
// Exercises: D0002, D0003, …     (every decision the file relies on)
// Provisional: OQ-nnn, …          (omit if nothing is provisional)
```
